# 筋トレ記録 — iPhone向けPWA試作品

## 機能
- 日付ごとの記録：種目・重量・回数をセット別に入力
- セット追加時に直前の重量と回数を引き継ぐ
- 日付ごとの履歴閲覧・編集・削除
- 種目別の最高使用重量・推定1RMグラフ
- JSONバックアップ書き出し・読み込み
- ローカル保存・サービスワーカーによるオフライン対応
- 広告・ログイン・解析コード・サーバーへの記録送信なし

## 開く方法
- 最初の画面・操作の確認：index.html をPCブラウザで開く（オフラインキャッシュ機能はここでは無効）。
- iPhoneのホーム画面アプリとして使う：フォルダ内のファイル全部を、HTTPSが使える静的Webホスティング（GitHub Pagesなど）に配置する。iPhoneのSafariで公開URLを開き、共有 → ホーム画面に追加。
- ホーム画面から起動したアプリとSafariタブでは、保存領域が分かれる場合があるため、基本的にはホーム画面から利用する。

## 注意
- データは端末内のWebストレージ(localStorage)に保存。iCloud同期はしない。
- SafariのWebサイトデータ削除、端末交換、再インストールなどで消失する可能性がある。定期的に「設定 → 書き出す」を使いバックアップを確保する。
- ホスティングにアップロードするのはアプリのソースコード（記録データを含まない）。公開URLを知っている人は画面にアクセスできるが、他人の端末にユーザーの記録が同期されることはない。
- 公開前の動作確認を推奨。WebKitのバージョンやOSの設定によって表示・保存動作が異なる場合がある。
