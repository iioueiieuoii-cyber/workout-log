# 筋トレ記録 — iPhone向けPWA Ver.0.5

GitHub Pagesで配信する、個人用筋トレ記録アプリです。広告・ログイン・バックエンドなし。

## Ver.0.5の変更点
- 各セットの重量と回数を上下スクロールで選択するリール入力に変更（重量：自重または0〜200kg・2.5kg刻み、回数：1〜30回）
- 「＋ セットを追加」は空欄で追加。ボタンを少し大きく変更
- 保存ボタンを廃止、入力・追加・削除と同時に端末内へ自動保存。途中入力の下書きも復元
- 休憩タイマー（60/90/120/180秒、初期90秒、手動スタート/一時停止/リセット）
- タイマー終了音は初期オフ（オンの場合でも、iPhoneの音楽との混在は実機次第）。画面ロック中の通知は保証しない
- 総負荷量：全種目または種目別、直近7日/今月/指定年（暦年）
- 「広告なし・個人用」ラベルを削除

## 既存データとの互換性
- 保存済み履歴はVer.0.1と同じ `personal-workout-log-v1` キーを使います。
- 入力途中の下書きは新しい別キーに保存します。
- JSONバックアップは旧版の形式を引き続き読み込めます。自重を含むバックアップはVer.0.1では復元できません。
- 更新前に「設定」→「書き出す」でバックアップを取ってください。

## GitHub Pagesへの更新
1. ZIPを解凍して `workout-log` フォルダ内の7つのファイルを選びます。
2. GitHubリポジトリの Code → Add file → Upload files で、既存の同名ファイルを上書きするようにアップロードしコミットします。
3. GitHub Pagesで公開したURLを開き、最新画面を確認します。変更が反映されない場合は完全に終了して開き直してください。

## 重要事項
- 端末間で記録は自動同期されません。
- Webサイトデータを消すと記録が失われる場合があります。定期的なバックアップを推奨します。
- 総負荷量は数値重量×回数のみ集計します。自重はkg換算しません。
- リール入力は保存時の値を決定ボタンで確定します。

## Ver.0.5 追加変更
- ヘッダーを「Workout Log」に変更し、オリジナルのノーズアート風アスリートのイラストを追加。
- 休憩タイマーの音声を、START操作時に準備する継続AudioContextに変更。3連続の短い通知音と画面上の終了表示。
- 「♪ 音をテスト」を追加。iOSの消音モード、ブラウザ音声制限、画面ロック等により音が鳴らない場合があります。
- 既存のローカル記録キー／データ形式を維持。アプリ更新の前にバックアップを推奨。

### 更新方法
GitHub Pagesのリポジトリ直下に、このフォルダ内の **8ファイルすべて** をアップロードし、同名ファイルは置き換えてください。


## Ver.0.5の変更点
- ヘッダーをC案（黒髪・青緑の作業服のオリジナルキャラクター）に変更。背景の星を削除、表示サイズを控えめに調整。
- タイマー終了音を「6回の短音×3節」（合計約3.4秒）に変更。音の波形と音量設定を調整。
- 終了時に画面を暗くし「休憩終了！」のモーダル画面を表示。OKで閉じて音も止める。
- 音量・消音の設定と他アプリの音楽再生についてはiOSの制約があります。音量の上昇や非干渉を保証するものではありません。
- 既存の筋トレ記録と下書きのローカルストレージキー・バックアップ形式は変更していません。

## アップロード手順
ZIPを展開し、workout-log フォルダ内の8ファイルをGitHubのリポジトリ直下にアップロードしてください。フォルダ自体をネストしないでください。

## Ver.0.5での変更点
- 重量・回数の選択を左右スワイプできる慣性付き横型リールに変更（フリック時はスクロールスナップで停止）。
- 同じ日の同じ種目の直前の入力値をリールの開始位置に使用。次セットの入力欄自体は空欄。
- ヘッダーを採用済みのB案（明るい金髪のドラゴンガール風）に変更。`hero-banner.jpg` はイラストとロゴを含むバナーです。
- 保存キー・記録形式・タイマーの動作は従来版と共通。

### 更新時の注意
- アプリの「設定」からバックアップを取得してから更新してください。
- GitHubのリポジトリ直下にZIP内の全ファイルをアップロードしてください。`hero-athlete.png` はVer.0.5では使用しません。GitHubに残っていても問題ありません。
- ホーム画面からの起動が古い画面のままなら、Safariで公開URLを一度開いてからホーム画面アプリを再起動してください。アプリを削除すると保存データを失う可能性があります。
